# Personal data redaction guardrail

Guardrail that detects and redacts personal identifiers in agent inputs and outputs, configurable per country.

## Overview

Rules and patterns for national ID numbers, phone numbers and addresses in 30 countries, applied before data leaves the administration.

## Interfaces

Protocol: `other`. Languages: en, es, fr.
